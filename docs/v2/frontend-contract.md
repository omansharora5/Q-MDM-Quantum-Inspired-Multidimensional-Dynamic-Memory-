# V2 UI contract

The existing authenticated API remains. Bearer key stored in tab sessionStorage.
No real ChatGPT/Claude histories may be fabricated. All sample conversations are synthetic.

- GET /api/state?dataset=personal-assistant (omit dataset for all): existing state fields plus datasets [{id,label,memories,synthetic}], memory_revision (changes only on knowledge writes), messages [record], and experiments_available. Memory payload now has dataset, visibility=shared/private, shared_with, links [{target_id,relation}], claim_key/value. Source has occurred_at (ISO timestamp), speaker, platform, session_id. Old records missing fields remain readable. Activity/traces/presence are real.
- GET /api/graph?dataset=...&revision=N (optional knowledge revision): nodes/edges/revision/memory_revision, historical boolean. Every node: id,label,type,parent?,record?,detail?,updated_at,latest_message{text,at,speaker,platform},facets {semantic:[node IDs],temporal:[IDs],provenance:[IDs],collaboration:[IDs]}. Includes source, cue, agent, message, memory, project, task, version nodes. Every node can be focused and layered; retain IDs and positions across polls. Edges have source,target,type. Diff via stable edge identity; animate removed/added links after saved update.
- GET /api/timeline?dataset=...: {messages:[{id,role,text,at,platform,session_id,memory_ids,synthetic}],changes:[...],revision}. Show conversation outside graph and cross-link to nodes. Timeline source messages are exact evidence, not generated summaries.
- POST /api/demo {dataset:'personal-assistant'|'camera-lab'|'team-planning'} -> seed that dataset idempotently. Keep existing camera records in their own sample option; default personal-assistant welcome. Offer sample generation from a normal assistant user (preferences, travel/work planning, later change of plans), clearly synthetic.
- POST /api/demo/evolve {dataset:'personal-assistant'|'camera-lab'|'team-planning'} -> versioned change to a sample approach; changes cues/typed edges while preserving history. Returns changed memory id and before/after versions. Safe repeat returns same receipt. UI "Simulate change of plan" should actually call this and display graph diffs; no fake animation.
- PUT /api/memories/{id}: existing Write shape with full memory, expected_version, idempotency_key. Editor prefilled from memory payload allows change content, cues, status, typed links, source text. On409 keep editor open and show conflict. Do not clear evidence or silently overwrite. New memory supports dataset and existing fields.
- POST /api/recall: existing request plus dataset?, strategy ('pace','bm25','vector','beam','ppr','qwam'), intent? (optional inference), cursor? (optional previous trace handle). Response retains old fields plus intent[], evidence_forest[{source,target,relation}], conflicts[], answer_ready, missing[], continuation. qwam is experimental classical numerical simulation, never an improvement claim.
- GET /api/experiments -> saved benchmark JSON, status='not_run' until it exists. Results have methods[],categories[],aggregate [{method,recall_at_k,evidence_precision,coverage,context_chars,p50_ms,p95_ms}],by_category[],limitations[],run_at,dataset_hash. Display measured charts and methodology, never made-up metrics. Actual output file contract will be finalized by backend owner.

UI pages: graph; conversation/timeline; context/handoffs; agents; unified connect guide (ChatGPT, Codex, Claude Code, custom/local, REST); experiments. Keep existing page tasks, creation, auth. Guide: ChatGPT ordinary UI cannot silently access localhost memory; synthetic ChatGPT-like transcript is only a demo, API wrapper via SDK works, ChatGPT remote Apps/MCP requires HTTPS endpoint/public auth or supported custom integration and has not been installed. Clarify local REST is not HTTP MCP. No invented connection badges. No external deployments.

Visual: fix alignment, enlarge graph labels, make node positions stable and label collisions avoidable. Use SVG without new frontend dependency. Center selected node, layer tabs and breadcrumb/back per node, inner ego graph of actual neighbors. Project, memory, source, cue, agent, message and revision nodes all drill down. Orbit/pan/zoom/reduced-motion/pause work. Sidebar responsive and controls aligned. Provide an accessible list alternate to graph.

Implementation destination: integrated into the canonical `mnemograph/web/{index.html,style.css,app.js,icon.svg}`, served by the FastAPI dashboard mount. The `.work/ui-v2/web/` copies are retained build history; the contract checks (`.work/ui-v2/check_graph.cjs`, `.work/ui-v2/check_ui.py`) read the canonical files. Do not edit the stale copies.
